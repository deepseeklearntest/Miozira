# Miozira Prototype 0.1 — Locked Color Palette

**Decision:** v0.2  
**Design principle:** *Quiet interface, vivid reality.*

| Role | Hex | Intent |
|---|---|---|
| Child background | `#F2EEE7` | warm stone, low-stimulation field |
| Parent background | `#F6F3EE` | soft linen |
| Primary surface | `#E8E2D8` | quiet grouping |
| Secondary surface | `#DDD6CA` | subtle separation |
| Primary content | `#26312E` | deep green-charcoal |
| Secondary content | `#53605B` | readable secondary text |
| Muted content | `#6F7772` | low-priority adult content |
| Primary action | `#4F746B` | muted eucalyptus/teal |
| On primary | `#FFFFFF` | accessible action text |
| Secondary action | `#D6E2DE` | quiet action surface |
| On secondary | `#2E4943` | dark teal content |
| Border | `#B8B2A8` | soft structure |
| Focus | `#476D68` | accessible focus cue |
| Listening | `#607C8A` | calm slate-blue state |
| Neutral response | `#6B756F` | non-evaluative feedback |
| Parent warning | `#94604E` | muted clay |
| Parent error | `#875148` | adult-only destructive/error |

## Non-negotiable rule

> The concept illustration should normally be the most colorful element on the child screen.

No rainbow UI, neon backgrounds, reward colors, flashing gradients, correctness green/red, or color used to create urgency.
